# Каталог товаров

Проект представляет собой систему управления продуктами и категориями.

## Описание классов

### Класс Product
Содержит информацию о товаре:
- `name` - название товара
- `description` - описание товара
- `price` - цена товара
- `quantity` - количество на складе

### Класс Category
Содержит информацию о категории товаров:
- `name` - название категории
- `description` - описание категории
- `products` - список товаров в категории
- `category_count` - счетчик количества категорий (статическое поле)
- `product_count` - счетчик общего количества товаров (статическое поле)
